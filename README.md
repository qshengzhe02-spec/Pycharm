# Reservoir Lithology Identification Using Advanced Intelligent Algorithms

Code execution examples can be found in the following files: [TabPFN2](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TabPFN-2%EF%BC%88%E7%89%88%E6%9C%AC2.2.1%EF%BC%89/TabPFN2.py), [TabPFN3](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TabPFN-3/TabPFN3.py), [XGB720](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/XGBoost/XGB720.py), [light](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/LightGBM/light.py), and [xintrc](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TRC/xintrc.py).

- The files [TabPFN2](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TabPFN-2%EF%BC%88%E7%89%88%E6%9C%AC2.2.1%EF%BC%89/TabPFN2.py) and [TabPFN3](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TabPFN-3/TabPFN3.py) use TabPFN classifiers to train lithology identification models and optimize the n_estimators hyperparameter. They implement missing-value imputation, feature standardization, and categorical encoding. The scripts automatically generate an Excel report summarizing the optimization results, confusion matrix images, the optimal model files, and prediction results for the test set.
- The file [XGB720](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/XGBoost/XGB720.py) performs exhaustive Cartesian grid search for XGBoost hyperparameter tuning, covering a total of 720 parameter combinations. An early-stopping strategy is employed to prevent overfitting. The script generates a summary of the grid search results, confusion matrix plots, feature importance plots, test-set prediction files, and experimental timing records.
- The file [light](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/LightGBM/light.py) performs multiclass grid search for LightGBM, evaluating all parameter combinations and capturing training exceptions. It generates an Excel report of the optimization results and confusion matrix images, while recording the time required for grid search and test-set inference.
- The file [xintrc](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TRC/xintrc.py) implements the FT-Transformer+TRC model with a representation correction module. Hyperparameter grid search is performed to identify the optimal FT backbone network. The backbone is then frozen, and the TRC correction head is trained. Evaluation metrics are generated separately for the original FT-Transformer and FT-Transformer+TRC models. The script also saves confusion matrix images and comprehensive experimental timing records.

The ablation experiment scripts, including [xiaorong实验](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/XGBoost/xiaorong%E5%AE%9E%E9%AA%8C.py), [消融](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/LightGBM/%E6%B6%88%E8%9E%8D.py), and [xiaorongshiyan](https://github.com/qshengzhe02-spec/Pycharm/blob/main/%E7%A0%82%E5%88%86%E7%B1%BB%E7%B2%97/TRC/xiaorongshiyan.py), are designed for XGBoost, LightGBM, and FT-Transformer+TRC, respectively. These scripts conduct controlled ablation experiments by fixing one hyperparameter at a time while performing grid search over the remaining hyperparameters. An optimization summary table is generated for each experiment, together with a CSV file summarizing the total execution time of all ablation experiments.

The dependencies required for this project are listed in the requirements file, which specifies the library versions used in the experiments reported in this paper.
All numerical experiments in this study were conducted on the Windows platform. The hardware configuration consisted of an AMD Ryzen 5 5600H processor (3.30 GHz) and 16 GB of RAM. The FT-TRC deep learning model supports GPU acceleration, whereas TabPFN, XGBoost, and LightGBM can run on the CPU.
